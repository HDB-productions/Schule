# Three.js model export helpers

Unmodified official Three.js r180 sources, downloaded 2026-11-07:

- [GLTFExporter.js](https://raw.githubusercontent.com/mrdoob/three.js/r180/examples/jsm/exporters/GLTFExporter.js)
- [GLTFLoader.js](https://raw.githubusercontent.com/mrdoob/three.js/r180/examples/jsm/loaders/GLTFLoader.js)
- [BufferGeometryUtils.js](https://raw.githubusercontent.com/mrdoob/three.js/r180/examples/jsm/utils/BufferGeometryUtils.js)

MIT license: see `LICENSE`. The main Three.js renderer comes from the existing `Physik/Energie/dynamot-labor/dynamot-3d-vendor` directory. These files are used only for reproducible export and reload verification; the Edulo widget does not need to load them.
